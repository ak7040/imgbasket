Four steps to an image link

  1. Open the uploader. Go to imgbasket.com. The upload box is at the top of the page and works on desktop and mobile.
  2. Add your image. Drag and drop it, paste it from the clipboard with Ctrl + V (⌘ + V on a Mac), or press Choose files. You can select several files at once.
  3. Pick a delete time if you want one. Delete after offers 1 hour, 1 day, 7, 30 or 90 days. The default, Keep forever, leaves the link active until you remove the file.
  4. Copy the link. The result box shows the page link and the direct link, plus tabs for Markdown, HTML and BBCode. Press Copy next to the one you need.

There is no confirmation step and no email. The link is live as soon as the upload finishes.

Upload an image and get a link on your phone

The uploader is a normal web page, so it works in Safari, Chrome and Firefox on iOS and Android. Tap the upload box, choose Photo Library or Camera, then copy the link from the result. On mobile, the copy button puts the link on the clipboard so you can paste it into any app. The result also shows a QR code for the direct link, which is handy when you need to move an image from a computer to a phone.

Where the link works

  • Forums: use BBCode, or the direct link inside an existing [img] tag. See image hosting for forums.
  • Reddit and Discord: paste the direct link, or the Markdown version. Both render automatically.
  • Your own website: use the HTML tab or drop the direct link into an <img src="…">. Hotlinking is allowed.
  • Marketplaces and listings: use the direct link. Keep the upload on Keep forever so the listing doesn't lose its image.
  • Documents and tickets: use the page link, or a short delete-after time if the screenshot should not stay online.

What happens to the image after you upload it

{{SITE_NAME}} is a link-only image host. The upload gets a random link, its page is marked noindex, and it is not added to a public gallery or the sitemap. Only someone with the link can open it. There is no account attached to the file; the site stores an IP address for rate limiting and abuse reports, as described in the Privacy Policy. Uploads are limited to 30 per hour per IP address.

Links are not password-protected. Anyone who has a link can open it and can forward it, so don't upload anything you would not want a stranger to see. If you need the file to disappear on its own, choose a temporary hosting time before uploading.

Common questions

Do I need an account to get an image link?

No. Uploading and copying a link works without an account, email address or password. That is true for images, videos and every link format.

Is there a file size limit?

Up to {{MAX_UPLOAD}} per file. The limit is shown under the upload box before you choose a file. The original is stored and served, so the direct link is not a compressed copy.

Why does my link show a preview in chat apps?

Each page has an Open Graph preview image made at upload time, so WhatsApp, Telegram, Discord, X and Facebook show the picture instead of a blank box. Videos use a poster frame when FFmpeg is available.

Can I delete the image after sharing the link?

There is no per-file delete button on the public site, because there is no account to attach it to. Use the Delete after option before uploading if the file is temporary, or contact the site using the Report link on the file's page.

Can I use the link commercially?

You can use the link for a website, listing or document you own, as long as you have the rights to the image. Don't upload other people's work without permission. The Terms of Use cover the rules.
