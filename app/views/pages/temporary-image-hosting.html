What happens when the timer ends

  1. The page link and the direct link stop working.
  2. The file is removed from storage in routine cleanup, so it is not kept “just in case”.
  3. Nothing needs to be done by you. There is no reminder to dismiss and no button to press.

If you copy an image into a chat or a forum post before it expires, the copy stays — the timer removes the file at your link, not the versions other people saved. Treat temporary hosting as a way to limit how long a URL works, not as a recall button.

What temporary hosting does not do

  • It does not recall copies. If someone downloaded, screenshotted or embedded the image while the link worked, deleting the original does not remove their copy.
  • It does not add a password. The link is the only access control. Anyone with it can view the file until the timer ends.
  • It cannot be extended. Choose the time carefully; there is no edit or cancel button after the upload.
  • It is not a permanent archive. For a forum signature or a long-lived listing, use Keep forever instead.

Common questions

Can I make an image delete after one view?

No. {{SITE_NAME}} offers timed deletion, not view-limited or burn-after-reading links. For a “delete after first open” link, use a service built for that.

Can I extend or cancel the timer?

No. The choice is fixed at upload time. If you need a longer-lived copy, upload the file again with Keep forever or a longer time before the first link expires.

Does an expired image disappear from Google?

Uploads are never indexed in the first place: pages and files send noindex and are not in the sitemap. Expiry removes the file itself, so the link returns nothing even if someone saved it.

Are temporary uploads private?

They are link-only, but not password-protected. Anyone with the link can view the file until it expires. See private image hosting for what that covers.

Is there a limit on temporary uploads?

No storage quota and no paid tier. Uploads are rate-limited to 30 per hour per IP address, and each file can be up to {{MAX_UPLOAD}}.
