How to move an image from Imgur

  1. Open the image on Imgur and download the original file — not the page, and not the compressed version, if you still have the source.
  2. Drop it on the {{SITE_NAME}} home page, or paste it with Ctrl + V. It uploads straight from your browser.
  3. Copy the link you need from the result: page link, direct link, Markdown, HTML or BBCode.
  4. Replace the old Imgur link wherever you posted it. Old links keep working until you change them; there is no automatic redirect between the two sites.

Where Imgur is still the better choice

Being honest: Imgur is a community as well as a host. It has public galleries, comments, voting and a developer API, and it is the right tool if you want your image to be discovered by other people. {{SITE_NAME}} has none of that. It is a plain host for images you are going to link to yourself — forums, chat, a blog, a support ticket or documentation. If you need albums, accounts or an API, this is not a drop-in replacement for those features yet.
