How it works

The site runs on PHP with a MySQL database. Uploaded files are stored in Telegram — the messaging platform — either in the operator's Saved Messages or in a private channel managed by a bot. Telegram is used as the storage layer; images are served back through {{SITE_NAME}} with the same links either way. A small disk cache keeps recent files fast for visitors.

Two preview sizes are generated for each image: a JPEG for chat-app link previews and a WebP for the gallery grid. The direct link always points at the original file, not the preview.
