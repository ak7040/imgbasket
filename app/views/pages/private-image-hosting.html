Private image hosting: link-only, no public gallery

{{SITE_NAME}} is private by default. There is no public gallery or recent-uploads feed, every upload page is marked noindex, and nothing is added to the sitemap. You upload an image, get a random link, and decide who receives it. No account is involved at any point.

What “private” means on {{SITE_NAME}}

  • No public gallery. There is no page that lists uploads, no “recent images” feed and no profiles to browse. The home page is an uploader, not a community.
  • No search indexing. File pages send noindex, nofollow, and the sitemap includes only the site's own pages — never your uploads.
  • A random link. Each upload gets a long, unguessable token, so nobody can find it by trying short or predictable URLs.
  • No account or email. Nothing ties the file to a profile, because there is no profile. You can upload and share without identifying yourself.
  • Delete after. Choose 1 hour, 1 day, 7, 30 or 90 days and the link stops working at that time. Useful for screenshots sent to one person.
  • No ad trackers. No advertising scripts anywhere, and the private file pages you share load no analytics and set no cookies.

What “private” does not mean

Private hosting is easy to misunderstand, so here is the honest version:

  • It is not password protection. Anyone with the link can open the file. If you send the link to a group chat, everyone in it can see the image and forward the link.
  • It is not encryption. The image is stored and served as a normal file. Treat the link like a password and share it only with people you trust.
  • It is not total anonymity. Each upload records the connection's IP address for rate limiting and abuse reports. There is no account, but the request is not invisible. The Privacy Policy lists exactly what is kept.
  • It is not permanent storage. There is no automatic deletion on Keep forever, but a free service cannot promise that a file stays online forever. Keep your own copy of anything important.

How to upload a private image

  1. Open the uploader.
  2. Drop the image or video, paste it, or choose a file. Files up to {{MAX_UPLOAD}} are accepted.
  3. Set Delete after if the file is temporary. Otherwise leave it on Keep forever.
  4. Copy the page link or the direct link. The page link is better for people; the direct link is for websites and apps.
  5. Send the link through the channel you already trust — a direct message, an email, a ticket — rather than posting it somewhere public.

When link-only hosting is the right choice

  • Client previews and drafts: send a link, replace the file when the design changes, and use a 7- or 30-day timer.
  • Support screenshots: share the exact error with one person, then let it expire.
  • Marketplace photos: a direct link that works in a listing without publishing the image to a public feed.
  • Forum posts: the direct link still works inside BBCode or an <img> tag; see image hosting for forums.
  • Personal photos and documents: keep them out of search results and away from galleries, with a short expiry if they are sensitive.

When you should use something else

If the image must be protected by a password, encrypted at rest, or shared with a team through accounts and permissions, use a service built for that. {{SITE_NAME}} is a free, link-only image host, not a secure vault. Common questions

Can Google find my image?

Not through us. Upload pages carry noindex, nofollow, direct files and previews send X-Robots-Tag: noindex, and uploads are never added to the sitemap. If you post the link somewhere public, though, search engines can follow that public page to it.

Can I delete an image after uploading it?

There is no per-file delete button on the public site, because there is no account to attach it to. Set Delete after before uploading for anything temporary, or use the Report link on the file's page to ask for removal.

Are uploads encrypted?

Traffic to the site uses HTTPS, so the link and the file are encrypted in transit. Files are stored in Telegram and streamed through the site; they are not end-to-end encrypted with a key that only you hold.

Is there a limit on private uploads?

No storage quota and no paid tier. Uploads are rate-limited to 30 per hour per IP address, and each file can be up to {{MAX_UPLOAD}}.
