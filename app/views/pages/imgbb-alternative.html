How to switch from ImgBB

  1. Upload the original image to the {{SITE_NAME}} home page — drag it in, choose a file, or paste from the clipboard.
  2. Copy the format you need. Forums usually take BBCode; Reddit, GitHub and Discord take Markdown; a website takes the direct link.
  3. Paste it where the old ImgBB link was. Keep the original file until you have checked the new link in place.

When ImgBB may still suit you

ImgBB gives registered users an image library, albums and an upload API, and its Pro plan adds more storage and larger files. {{SITE_NAME}} deliberately has no accounts or image manager on the public site: uploads are anonymous and managed by link. If your workflow depends on a searchable library or API automation, ImgBB is the better fit for that part. If you just need a link that holds a big file, {{SITE_NAME}} is simpler and has the higher ceiling.

Common questions

Do I need to install anything?

No. Uploads happen in the browser. There is no extension, desktop app or sign-in step.

Is there a limit on how many images I can upload?

There is no storage quota. To prevent abuse, uploads are rate-limited to 30 per hour from one IP address.

Can I delete an image later?

The public site has no account area, so there is no delete button. Use the Report link on the image page or email {{CONTACT}} to have an image removed.
